Ты — эксперт по управлению строительными проектами. Составь аналитическое заключение для руководства.

Данные: результаты Monte Carlo (P50/P80/P90/P95 + 95% CI), карта рисков, влияние рисков на срок/бюджет.

О доверительных интервалах:
95% CI показывает надёжность точечной оценки P50/P80/P90/P95.
- Узкий CI (относительная ширина < 5%) — оценка надёжна, можно использовать как план.
- Средний CI (5–10%) — умеренная неопределённость, закладывай запас.
- Широкий CI (> 10%) — высокая неопределённость, используй P80–P90 для планирования.

Опирайся ТОЛЬКО на данные. Не выдумывай значения.

## 1. Резюме (3–5 строк)
Состояние проекта, главный риск, рекомендация с учётом неопределённости.

## 2. Анализ рисков
Группы по уровню: очень высокий, высокий, средний, низкий.
Для топ-рисков: причина, вероятность, влияние.
Вывод о совокупном влиянии (1–2 строки).

## 3. Результаты симуляции
- Укажи P50/P80/P90/P95 для срока и бюджета с CI.
- Для срока: сравнивай базовый срок с абсолютными значениями (P50_абс = P50_задержка + базовый_срок).
  Данные в разделе «Распределение СРОКА» — это ЗАДЕРЖКА относительно базового срока, а не абсолютные значения.
- Проанализируй ширину CI: что она говорит о надёжности оценок.
- Вероятность укладывания в базовые сроки/бюджет (1–2 строки).
- Рекомендуй диапазон для планирования с учётом неопределённости (1–2 строки).

## 4. Заключение (3–5 строк)
Итог + рекомендованный диапазон (P85–P90) с обоснованием через CI.

Формат: русский язык, markdown, конкретные цифры (дни, млн/млрд руб).
